# Games

A collection of browser games built in a single web project.

## Overview
This repository is a small gaming website featuring multiple mini-games and interactive experiences in one place. It is designed as a fun, lightweight web app with a simple front-end setup.

## Features
- Multiple game sections in one app
- Simple and responsive UI
- Browser-based gameplay
- Easy to extend with more games

## Tech Stack
- JavaScript
- CSS
- HTML

## Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Sarthak-Budhodkar/Games.git
   ```
2. Open the project folder.
3. Launch `index.html` in a browser, or serve it locally:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000`.
